# JBMセミナー LP

Joint Breathing Method™セミナーのランディングページです。

## 公開手順（GitHub Pages）

1. GitHubで新しいリポジトリを作成
   - リポジトリ名の例：`jbm-seminar-lp`
2. `index.html` を、そのままリポジトリのルートにアップロード
3. リポジトリの「Settings」→「Pages」を開く
4. 「Source」を `main` ブランチ・`/ (root)` に設定して保存
5. 数分待つと、`https://（あなたのGitHubユーザー名）.github.io/jbm-seminar-lp/` で公開される

## デザインコンセプト

「新幹線理論」（各駅＝理論を飛ばして、最短で結果へ）を、
ヒーローセクションの路線図モチーフとして視覚化しています。
配色は紺（信頼感）×ブルー（メインアクセント）×レッド（CTA限定）。
カリキュラム部分は「時刻表」のような等幅フォントの表組みにし、
新幹線というモチーフに一貫性を持たせています。

## 修正したい場合

`index.html` の中の日本語テキスト部分（見出し・本文）を直接編集すれば、
文言だけの調整はすぐに反映できます。配色を変えたい場合は、
ファイル冒頭の `:root{ }` 内にある色の変数（`--blue`・`--red`等）を
書き換えてください。

## 申込ボタンのリンク先について

現在、申込ボタンのリンク先は `#apply`（ページ内の開催概要セクション）に
なっています。実際の申込フォーム・LINE等のURLが決まったら、
`index.html` 内の `href="#"` および `href="#apply"` の該当箇所を、
実際のURLに差し替えてください。
